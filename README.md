Personal portfolio website for Guillaume Sainthillier, a freelance web developer based in Toulouse, France.

**Live site:** [https://sainthillier.fr](https://sainthillier.fr)

Design inspired by [BlackrockDigital agency template](https://github.com/StartBootstrap/startbootstrap-agency).

## Tech Stack

- **[Hugo](https://gohugo.io/)** - Static site generator
- **[Vite](https://vitejs.dev/)** - Modern build tool for JavaScript and CSS bundling
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Utility-first CSS framework
- **[Lucide](https://lucide.dev/)** - SVG icons (only the icons used are imported, see `assets/js/icons.js`)
- **Skills word cloud** - packed at build time into SVGs by `scripts/skills-cloud.js` ([opentype.js](https://opentype.js.org/) + the [Arimo](https://fonts.google.com/specimen/Arimo) font)
- **JavaScript libraries:**
    - [lite-youtube-embed](https://github.com/paulirish/lite-youtube-embed) - Lightweight YouTube embeds
    - [@webcomponents/custom-elements](https://github.com/webcomponents/polyfills/tree/master/packages/custom-elements) -
      Custom Elements polyfill
- **[Biome](https://biomejs.dev/)** - JavaScript linting and formatting
- **[Prettier](https://prettier.io/)** - CSS, Markdown and YAML formatting

## Features

- 📱 Responsive design optimized for all devices
- ⚡ Fast page loads with static site generation
- 🎨 Modern UI with Tailwind CSS v4
- 🔧 Custom JavaScript components (modals, collapses) with Bootstrap-like API
- 🖼️ Responsive WebP images generated by Hugo image processing, with native lazy loading
- 🚀 Automatic deployment to Netlify
- ✨ Pre-commit hooks for code quality (Biome, Prettier)

## Prerequisites

- [Node.js](https://nodejs.org/) 24 (version used in CI)
- [Yarn](https://yarnpkg.com/) 1.x package manager
- [Hugo Extended](https://gohugo.io/installation/) — no separate install needed: the `hugo-extended` dev dependency
  provides the `hugo` binary used by the `yarn hugo*` scripts

## Installation

```bash
# Clone the repository
git clone https://github.com/guillaume-sainthillier/sainthillier.fr.git
cd sainthillier.fr

# Install dependencies
yarn install
```

## Development

```bash
# Build assets in development mode
yarn dev

# Watch mode for asset development (auto-rebuild on changes)
yarn watch

# Run Hugo dev server with drafts enabled
yarn hugo:dev

# For full development workflow:
# 1. Run `yarn watch` in one terminal
# 2. Run `yarn hugo:dev` in another terminal
```

The site will be available at `http://localhost:1313/`

## Build

```bash
# Build production assets only
yarn build

# Build assets + Hugo site (production)
yarn build:hugo

# Build with drafts and future posts (preview)
yarn build:hugo:preview
```

The production site will be generated in the `public/` directory.

## Code Quality

```bash
# Lint and format JavaScript in assets/ with Biome (writes fixes)
yarn lint

# Biome check without writing (used in CI)
yarn lint-ci

# Format CSS, Markdown and YAML with Prettier (writes)
yarn prettier

# Prettier check without writing (used in CI)
yarn prettier:check

# Run both fixers (yarn lint && yarn prettier)
yarn format

# Check for unused dependencies/exports
yarn knip

# Auto-fix unused dependencies/exports
yarn knip:fix

# Print the built bundle sizes as JSON (after yarn build)
yarn size:json
```

Pre-commit hooks (Husky + lint-staged) run Biome on staged `js/jsx/ts/tsx/mjs/json` files and Prettier on staged
`css/md/yaml/yml` files.

## Continuous Integration

GitHub Actions workflows in `.github/workflows/`:

- **Continuous Integration** (pull requests and pushes to `main`): `yarn lint-ci`, `yarn prettier:check` and
  `yarn knip`
- **Bundle Size** (pull requests): builds the base and PR branches and comments the bundle size difference

## Architecture

### Build Pipeline

1. **Vite** (`vite.config.js`) bundles JavaScript and CSS from `assets/` (entry: `assets/js/app.modern.js`) to
   `static/build/`
2. A custom Vite plugin generates `data/entrypoints.json` with asset paths for Hugo
3. **Hugo** generates static HTML from `layouts/` and `content/` to `public/`, processing images and PDFs from `assets/`

### Project Structure

```
.
├── assets/          # Source files
│   ├── css/         # Tailwind CSS files (Vite)
│   ├── js/          # JavaScript modules (Vite)
│   ├── images/      # Images processed by Hugo
│   ├── pdf/         # PDFs (CV, CGV) published by Hugo
│   └── svg/         # Logos
├── content/         # Markdown content pages
├── layouts/         # Hugo templates
│   ├── _default/    # Base templates
│   ├── partials/    # Reusable components
│   └── shortcodes/  # Content shortcodes
├── scripts/         # Tooling scripts (bundle size report)
├── static/          # Static assets copied as-is (favicons, manifest, robots.txt)
│   └── build/       # Vite output (generated)
├── data/            # Generated by Vite (entrypoints.json)
└── public/          # Generated site (build output)
```

## Deployment

The site is automatically deployed to Netlify on every push to the main branch.

- **Hosting:** Netlify (configured in `netlify.toml`)
- **Build command:** `yarn build:hugo`
- **Publish directory:** `public/`
- **Deploy previews:** built with `--baseURL $DEPLOY_PRIME_URL` so absolute links resolve on the preview URL
