[![Netlify Status](https://api.netlify.com/api/v1/badges/39c2daaf-f794-4e77-b38f-1aae8df9c012/deploy-status)](https://app.netlify.com/sites/sainthillier/deploys)

Personal portfolio website for Guillaume Sainthillier, a freelance web developer based in Toulouse, France.

**Live site:** [https://sainthillier.fr](https://sainthillier.fr)

Design inspired by [BlackrockDigital agency template](https://github.com/StartBootstrap/startbootstrap-agency).

## Tech Stack

- **[Hugo](https://gohugo.io/)** - Static site generator, which also builds the CSS (Tailwind CLI) and the JavaScript
  (esbuild)
- **[TypeScript](https://www.typescriptlang.org/)** - Browser code in `assets/js/` and Node scripts in `scripts/`,
  type-checked by `pnpm typecheck` (esbuild and Node only strip the types)
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Utility-first CSS framework
- **[Lucide](https://lucide.dev/)** - SVG icons, inlined at build time from `lucide-static` (`layouts/partials/icon.html`)
- **[Fontsource](https://fontsource.org/)** - Plus Jakarta Sans and Inter, subset into `assets/fonts/` by `pnpm fonts:subset`
- **[Biome](https://biomejs.dev/)** - TypeScript linting and formatting
- **[Prettier](https://prettier.io/)** - CSS, Markdown and YAML formatting

## Features

- 📱 Responsive design optimized for all devices
- ⚡ Fast page loads with static site generation
- 🎨 Modern UI with Tailwind CSS v4
- 🔧 Lightweight JavaScript (mobile menu, portfolio filters, contact form), no framework
- 🖼️ Responsive WebP images generated by Hugo image processing, with native lazy loading
- 🚀 Automatic deployment to Netlify
- ✨ Pre-commit hooks for code quality (Biome, Prettier)

## Prerequisites

- [Node.js](https://nodejs.org/) 24 (version used in CI)
- [pnpm](https://pnpm.io/) — the version is pinned by `packageManager` in `package.json`
- [Hugo Extended](https://gohugo.io/installation/) — no separate install needed: the `hugo-extended` dev dependency
  provides the `hugo` binary used by the `pnpm hugo*` scripts

## Installation

```bash
# Clone the repository
git clone https://github.com/guillaume-sainthillier/sainthillier.fr.git
cd sainthillier.fr

# Install dependencies
pnpm install
```

## Development

```bash
# Hugo dev server with drafts: pages, CSS and JavaScript rebuilt on change
pnpm dev
```

On macOS, the `hugo-extended` package cannot download Hugo since 0.170 (no macOS "extended" release): point
`HUGO_BIN_PATH` at a standard Hugo binary of the same version, e.g. `HUGO_BIN_PATH=$(brew --prefix)/bin/hugo pnpm dev`.

The site will be available at `http://localhost:1313/`

## Build

```bash
# Build the site (production)
pnpm build

# Build with drafts and future posts (preview)
pnpm build:preview
```

The production site will be generated in the `public/` directory.

## Code Quality

```bash
# Type-check assets/js/ (tsconfig.json) and scripts/ (scripts/tsconfig.json)
pnpm typecheck

# Lint and format TypeScript in assets/ with Biome (writes fixes)
pnpm lint

# Biome check without writing (used in CI)
pnpm lint-ci

# Format CSS, Markdown and YAML with Prettier (writes)
pnpm prettier

# Prettier check without writing (used in CI)
pnpm prettier:check

# Run both fixers (pnpm lint && pnpm prettier)
pnpm format

# Check for unused dependencies/exports
pnpm knip

# Auto-fix unused dependencies/exports
pnpm knip:fix

# What a visitor downloads (pages, inlined CSS, JS, fonts) as JSON, after pnpm build
pnpm size:json
```

Pre-commit hooks (Husky + lint-staged) run Biome on staged `js/jsx/ts/tsx/mjs/json` files and Prettier on staged
`css/md/yaml/yml` files.

## Continuous Integration

GitHub Actions workflows in `.github/workflows/`:

- **Continuous Integration** (pull requests and pushes to `main`): `pnpm typecheck`, `pnpm lint-ci`,
  `pnpm prettier:check` and `pnpm knip`
- **Bundle Size** (pull requests): builds the base and PR branches and comments the difference in what a visitor
  downloads (each page Brotli-compressed with its inlined CSS, the JavaScript bundle, the fonts)

## Architecture

### Build Pipeline

Hugo does everything in one `hugo` run:

1. **CSS**: `layouts/partials/stylesheet.html` compiles `assets/css/app.css` with the Tailwind CSS CLI
   (`css.TailwindCSS`), publishes the fonts fingerprinted under `/build/fonts/` and inlines the stylesheet in
   production
2. **JavaScript**: `layouts/partials/script.html` bundles `assets/js/app.ts` with esbuild (`js.Build`) to
   `/build/app.<hash>.js`
3. **Pages**: static HTML from `layouts/` and `content/` to `public/`, processing images and PDFs from `assets/`

### Project Structure

```
.
├── assets/          # Source files
│   ├── css/         # Tailwind CSS files
│   ├── fonts/       # Subset web fonts
│   ├── js/          # TypeScript modules
│   ├── images/      # Images processed by Hugo
│   └── pdf/         # PDFs (CV, CGV) published by Hugo
├── content/         # Markdown content pages
├── layouts/         # Hugo templates
│   ├── _default/    # Base templates
│   ├── partials/    # Reusable components
│   └── shortcodes/  # Content shortcodes
├── scripts/         # Node tooling scripts in TypeScript (bundle size, fonts, OG image, CGV PDF)
├── netlify/         # Local Netlify build plugin (Hugo resource cache)
├── static/          # Static assets copied as-is (favicons, manifest, robots.txt)
└── public/          # Generated site (build output)
```

## Deployment

The site is automatically deployed to Netlify on every push to the main branch.

- **Hosting:** Netlify (configured in `netlify.toml`)
- **Build command:** `pnpm build`
- **Publish directory:** `public/`
- **Deploy previews:** built with `--baseURL $DEPLOY_PRIME_URL` so absolute links resolve on the preview URL
